Pass options to the constructor, or to a wrapper as props. Options marked **live** can change at any time with `grid.setOptions()`. Options marked **rebuild** (`cols`, `rows`, `cellSize`, `fill`) set the size of the tile mesh, so changing them means creating a new grid; the Vue, React and Web Component wrappers do that for you.

```ts
const grid = new SpacetimeGrid(el, { cols: 80, waveAmplitude: 0.12, theme: { hover: "#5ee6ff" } });
grid.setOptions({ rippleSpeed: 3.5 });
```

These tables are generated from `SPACETIME_GRID_SCHEMA`, the same data the sandbox builds its controls from, so they always match the code.
