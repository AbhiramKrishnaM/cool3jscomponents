
## How it fits on the page

- **Size:** the grid adds a `<canvas>` that fills its element and follows its size. You can also pass a `<canvas>` you already have.
- **Input:** the cursor and clicks are tracked on `window`, so the grid still reacts when it sits behind your content with `z-index: -1`. Positions are mapped onto the canvas, and anything outside it is ignored.
- **Phone layout:** below 1024px of canvas width (`compactBreakpoint`), the grid drops lower and shrinks a little, which suits phones.

<Aside type="tip">
  The cursor well only reacts to a mouse. On touch screens, taps still send ripples.
</Aside>

## Changing it while it runs

```ts
grid.setOptions({ waveAmplitude: 0.15, wellRadius: 3 });
grid.setTheme({ hover: "#5ee6ff" });
grid.ripple(window.innerWidth / 2, window.innerHeight / 2);
```

Most options change live. `cols`, `rows`, `cellSize` and `fill` set the size of the tile mesh, so changing them means creating a new grid; the framework wrappers do that for you. See [Options](/spacetime-grid/options/) for the full list.

## Cleaning up

```ts
grid.destroy();
```

`destroy()` stops the loop, removes the listeners and frees the GPU resources. The wrappers call it when they unmount.

## Reduced motion

Visitors with `prefers-reduced-motion: reduce` get a single still frame of the grid, with no waves, well or ripples. If they change the setting while the page is open, the grid switches over. Set `reducedMotion: "always"` or `"never"` to override this.
