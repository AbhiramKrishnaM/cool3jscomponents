`@abhiramkrishna/contribution-skyline` turns a year of GitHub contributions into glowing 3D bars: they rise week by week, twinkle, and the busiest days burst into falling pixels. It runs on its own or as a layer on the spacetime grid.

The package is being ported from the portfolio. Install steps, options and a live demo will land here.
