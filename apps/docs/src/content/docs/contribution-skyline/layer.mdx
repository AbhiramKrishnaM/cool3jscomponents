If your page already has a [spacetime grid](/spacetime-grid/), add the skyline to it as a plugin instead of creating a second scene. This is how abhiramkrishna.com does it.

![Bars standing on the animated grid](../../../assets/skyline/layer.png)

```ts
import { SpacetimeGrid } from "@abhiramkrishna/spacetime-grid";
import { contributionSkyline } from "@abhiramkrishna/contribution-skyline";
import data from "./data/contributions.json";

const grid = new SpacetimeGrid(document.querySelector(".background")!);
const skyline = contributionSkyline(data, { progress: () => aboutProgress() });
grid.use(skyline);
```

- **Floor:** the bars stand on the grid's tiles and move with its waves, wells and ripples.
- **Glow:** the days beneath light up through [`grid.glow`](/spacetime-grid/plugins/#working-with-tiles).
- **Colour:** the bars take the grid's highlight colour, unless you set `color`.

## Placement

By default, the 53 × 7 block sits in the middle of the grid. There are two other options:

```ts
contributionSkyline(data, { origin: { col: 4, row: 20 } });

contributionSkyline(data, {
  anchor: { ndc: [0, -0.45], pose: aboutPose },
});
```

- **`origin`** sets the first tile. The oldest day goes at the back left.
- **`anchor`** centres the block where a screen point (−1 to 1 on each axis) meets the grid, as seen from a camera pose. Use it when the camera moves between poses with [`scrollCamera`](/spacetime-grid/plugins/#scrollcamera) and the skyline should be in view at one of them.

## Rising with scroll

Pass `progress` as a function. It's read every frame, so the bars rise as you scroll down and sink as you scroll back up:

```ts
const about = document.getElementById("about")!;

contributionSkyline(data, {
  progress: () => {
    const start = about.offsetTop - innerHeight;
    const end = about.offsetTop - innerHeight * 0.4;
    return Math.min(1, Math.max(0, (scrollY - start) / (end - start)));
  },
});
```

When progress is 0, the bars, particles and glow are hidden and cost almost nothing.

## Changing it

```ts
skyline.setOptions({ barScale: 1.3, burstLevel: 3 });
skyline.setProgress(1);
skyline.setData(newData);

const remove = grid.use(skyline);
remove();
```

Removing the layer takes its meshes off the grid, clears the glow and frees its GPU resources.

<Aside>
  The layer follows the grid's motion setting. Under reduced motion, the bars show at `reducedMotionProgress` in the grid's still frame, with no twinkle or bursts.
</Aside>
